Vérifier si votre titre de séjour est prêt

Vérifiez l'état de votre demande en ligne

1) Vérifier avec le reçu du kit postal

Si vous avez envoyé votre demande avec le kit postal, vous pouvez vérifier l'état de votre permis sur le site du Portail de l'Immigration.

Vous aurez besoin de :

  • Le numéro de demande (vous le trouvez sur le reçu)
  • Votre code fiscal
🔗
Accéder au Portail de l'Immigration

2) Vérifier avec le numéro de demande

Vous pouvez également utiliser directement le numéro de demande, que vous trouvez sur le reçu du kit postal.

Le numéro se compose de :

  • Code de province (ex. MI pour Milan, RM pour Rome)
  • Code numérique

📊 Que signifient les différents statuts ?

  • In lavorazione (En traitement) : Votre demande est encore en cours d'examen
  • Convocazione in Questura (Convocation à la Questura) : Vous devez vous rendre à la Questura (Préfecture de police) pour un rendez-vous
  • Pronto per il ritiro (Prêt à retirer) : Votre permis est prêt ! Allez à la Questura (Préfecture de police) pour le récupérer
  • Spedito (Expédié) : Le permis a été envoyé à votre adresse

💡 Conseils utiles

  • Vérifiez régulièrement : Le statut peut changer à tout moment
  • Gardez le reçu : C'est le document qui prouve que vous avez déposé votre demande
  • Ne manquez pas les rendez-vous : Si vous êtes convoqué à la Questura, allez-y à la date indiquée
  • Gardez toujours le reçu sur vous : Jusqu'à ce que vous ayez le nouveau permis, le reçu prouve que vous êtes en situation régulière
⚠️
Attention : Si votre demande est "in lavorazione" (en traitement) depuis longtemps, contactez la Questura ou une organisation d'aide juridique pour vérifier qu'il n'y a pas de problèmes.
