Kit postal et autres formulaires

Téléchargez les formulaires nécessaires pour votre demande

📋 Déclaration d'hébergement

C'est un document que vous déposez lorsque vous hébergez gratuitement une personne étrangère chez vous (par exemple un ami, un proche, quelqu'un que vous aidez). Il n'y a pas de loyer.

Vous devez vous rendre à la Police (Poste de police ou Questura/Préfecture de police) dans les 48 heures suivant l'arrivée de la personne à votre domicile. Ils vous remettront un formulaire à remplir et tamponneront ensuite le document.

📥
Télécharger le formulaire

🏠 Mise à disposition du logement (cessione di fabbricato)

C'est un document que vous déposez lorsque vous louez une maison ou une chambre à quelqu'un contre paiement. La personne vous paie un loyer pour vivre dans votre bien.

Vous devez le soumettre à la Police locale (Police Municipale) ou au Poste de police dans les 48 heures suivant l'installation de la personne. C'est obligatoire par la loi pour les Italiens et les étrangers.

📥
Télécharger le formulaire

🏡 Déclaration de résidence

C'est le formulaire pour demander l'inscription au registre de la population (anagrafe) de la Mairie où vous habitez.

📥
Télécharger le formulaire

💰 Bulletin de versement postal pour le permis électronique

Pour payer le titre de séjour électronique, vous devez remplir un bulletin de versement postal.

  • Montant : 30,46 EUR pour le permis électronique
  • Compte postal : 67422402
  • À l'ordre de : Ministero dell'Economia e delle Finanze
  • Description : Importo per il rilascio del permesso di soggiorno elettronico

📮 Où obtenir le kit postal ?

Le kit postal pour demander ou renouveler votre titre de séjour est disponible gratuitement dans n'importe quel bureau de poste.

Le kit contient :

  • Le formulaire de demande
  • Les instructions pour le remplir
  • Un bulletin de versement
⚠️
Attention : Tous les permis ne se demandent pas avec le kit postal. Certains doivent être demandés directement à la Questura (Préfecture de police). Vérifiez sur la page du permis qui vous intéresse.
