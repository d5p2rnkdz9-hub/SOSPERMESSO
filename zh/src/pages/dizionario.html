难懂词汇词典

用简单的语言解释官僚术语

A

Accoglienza（接待） #

接待申请国际保护的人的中心和设施系统。

A carico（被抚养人） #

在经济上依赖他人的人。例如，一个没有工作的孩子是父母的"a carico"（被抚养人），因为父母支付其饮食、服装和其他费用。

Affidamento（寄养/监护） #

当未成年人（18岁以下的儿童或青少年）被交由其亲生父母以外的个人、家庭或机构照管时的安排。

Asilo（庇护） #

一种国际保护形式，适用于因存在被迫害风险（例如被杀害、酷刑、严重歧视）而无法返回本国的人。另见"Rifugiato"（难民）。

ASL #

Azienda Sanitaria Locale（地方卫生局）。管理某一地区医疗和卫生服务的办公机构。在这里您可以注册国家医疗服务并选择家庭医生。

Attestato nominativo（实名登记证明） #

申请庇护时 Questura（警察总部）发放的第一份居留许可，在等待发放黄色纸质许可期间使用。它与 C3 表格一起发放。它没有过期日期：在庇护申请审查结束前一直有效。

C

C3 #

在 Questura（警察总部）申请庇护时填写的表格，包含您的个人信息。

Carichi pendenti（未决案件） #

证明某人是否有尚未终审判决的刑事诉讼的证明文件。

Carta di soggiorno（居留卡） #

一个模糊的术语，可以指两种不同的居留许可：长期居留许可或欧盟公民家属居留卡。

CAS #

Centro di Accoglienza Straordinaria（特别接待中心）。临时安置已申请庇护人员的设施，由各省政府（Prefettura）设立和管理。另见"Accoglienza"（接待）和"SAI"。

Casellario giudiziale（犯罪记录） #

包含某人刑事定罪信息的登记册。需向检察院申请。

Cessione di fabbricato（房屋占用声明） #

当您将房屋或房间有偿出租给他人时需要办理的文件。您必须在48小时内将此文件提交给当地警察局。

Coesione familiare（家庭团聚） #

允许已在意大利的人获得居留许可，以便与已合法居住在意大利的家庭成员团聚的程序。

Codice Fiscale（税号） #

每人独有的个人代码，用于在意大利进行身份识别，以及办理工作、就医或签署正式文件等事务。

Commissione Territoriale（领土委员会） #

意大利政府机构，负责决定谁可以获得难民身份、辅助保护、特别保护或医疗许可。

Coniuge（配偶） #

丈夫或妻子。指与其结婚（婚姻）或建立民事结合关系的人。

Conversione（转换） #

将一种居留许可转换为另一种（例如从学习许可转为工作许可），无需返回原籍国。

Copia conforme（认证副本） #

文件的复印件上加盖官方印章，证明其与原件完全一致。可在市政厅、公证处或某些情况下在邮局办理。

D

Decreto di espulsione（驱逐令） #

Prefettura（省政府）作出的要求您离开意大利的决定。除驱逐外，还可能发出再入境禁令。

Dichiarazione di ospitalità（接待声明） #

由声明人签署的文件，表明其免费接待您在意大利的住所中居住。必须在48小时内提交给警察局。

Diniego（拒绝） #

否定决定。当您的申请被当局拒绝时。

Domicilio（住所） #

您居住的地址，即使是临时的。

E

Esternalizzazione（外部化） #

意大利和欧盟将移民管控委托给欧盟以外国家的一系列政策，目的是在人们抵达欧洲之前就阻止其出发。与利比亚或突尼斯达成的协议即为例子。

F

Frontiera（边境） #

两个国家之间的边界。在边境口岸（港口、机场、陆路口岸）会检查进出该国的人员。在边境也可以申请国际保护。

I

Idoneità alloggiativa（住房适宜性证明） #

证明房屋适合居住的证明（有足够的空间、安全、具备必要的服务设施）。必须向房屋所在地的市政厅申请。

K

Kit postale（邮局套件） #

在邮局领取的一套表格，用于申请或续签某些类型的居留许可。

M

Marca da bollo（印花税票） #

在烟草店购买并贴在正式文件（如向 Questura 提交的申请）上的税票。价格为16欧元（最常见面值），用于向国家缴纳税款。

Minore（未成年人） #

18岁以下的人。

Minore straniero non accompagnato（无人陪伴的外国未成年人） #

在意大利没有父母或其他具有法律责任的成年人陪伴的18岁以下人员。

N

Nulla osta（许可/批准） #

办理某事所需的官方许可。例如，"nulla osta al ricongiungimento familiare"（家庭团聚许可）是 Prefettura 批准您将家庭成员带到意大利的许可。

P

Permesso di soggiorno（居留许可） #

赋予您在一定时间内合法居住在意大利的权利的文件。

Prefettura（省政府） #

意大利国家机构，每个省都设有。负责处理公共秩序、安全以及外国人的某些手续，如公民身份和家庭团聚。

Protezione internazionale（国际保护） #

意大利给予因返回本国会面临危险而无法回国的人的保护。包括庇护和辅助保护。

Prosieguo amministrativo（行政延续） #

允许以未成年人身份抵达意大利的外国青年在年满18岁后继续获得支持的可能性。

Q

Questura（警察总部） #

设在每个省会城市的国家警察办公室。这是您申请、领取和续签居留许可的地方。设有一个名为"Ufficio Immigrazione"（移民办公室）的窗口。

R

Residenza（户籍地） #

您永久居住并在市政厅户籍登记处登记的地址。

Ricevuta（收据） #

证明您提出申请或付款的文件。Questura 收据（cedolino）证明您已申请居留许可，允许您在等待期间留在意大利。

Ricongiungimento familiare（家庭团聚） #

允许已持有效居留许可在意大利居住的外国人将某些家庭成员带到意大利的程序。

Rifugiato（难民） #

因受到迫害而逃离本国，因此可以在意大利获得难民身份的人。

Rinnovo（续签） #

在居留许可到期前延长其有效期的过程。

S

SAI #

Sistema di Accoglienza e Integrazione（接待与融入系统）。由各市政府（Comune）管理的中心网络，为庇护申请人和持有保护身份者提供接待和融入服务（意大利语课程、法律支持、帮助寻找住房和工作）。它取代了旧的SPRAR和SIPROIMI系统。另见"CAS"和"Accoglienza"（接待）。

Servizi sociali（社会服务） #

帮助困难群体（家庭、老人、残疾人、未成年人）的市政办公室。

Sportello Unico（一站式服务窗口） #

Sportello Unico per l'Immigrazione（SUI，移民一站式服务窗口）。Prefettura 下属的办公室，处理外国人的工作手续（许可、居住合同）和家庭团聚事宜。

Status di rifugiato（难民身份） #

Commissione Territoriale 或法院认定某人为难民的决定。获得难民身份后，您可以申请庇护居留许可。

T

Tribunale（法院） #

法官对法律事务作出裁决的场所。

Tribunale per i minorenni（少年法院） #

处理18岁以下人员相关法律事务的专门法院。

Tessera sanitaria（医疗卡） #

允许您使用国家医疗服务（家庭医生、急诊室、药品）的塑料卡。在获得居留许可和户籍登记后，在 ASL 申请。

Tutore（监护人） #

当父母无法照顾未成年人时，由法官选定的照顾18岁以下年轻人的人。

U

Udienza（庭审/听证） #

在法院与法官的会面。在99%的情况下，您的律师必须出席。

Unione civile（民事结合） #

意大利为同性伴侣提供的法律伴侣关系，类似于婚姻但在法律上有所不同。

V

Visto（签证） #

在出发前向您所在国家的意大利大使馆或领事馆申请的进入意大利的授权。有不同类型：旅游签证、学习签证、工作签证、家庭团聚签证。

Vincolo di parentela（亲属关系） #

两人之间的家庭关系（父母-子女、兄弟姐妹、祖父母-孙辈、叔伯姑姨-侄子女）。
