# Stamp

Il «timbro» sulla parola chiave di un titolo display, come **Facile**.

- Testo bianco su `sp-ink` pieno, raggio `radius-md`, padding 4px 22px 12px, `display: inline-block`.
- Ruotato di −5° (pagina) o −6° (stampa), con `transform-origin: left center`.
- Senza doppio bordo, senza ombra e senza punto finale.
- Uno solo per pagina o per volantino.
