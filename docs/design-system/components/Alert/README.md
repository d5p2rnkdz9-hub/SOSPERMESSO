# Alert

Riquadri di avviso dentro le pagine dei permessi, in tre livelli.

- **Da sapere:** fondo `state-info-tint`, icona «i» in `state-info`.
- **Attenzione:** fondo `state-warning-tint`, icona triangolo in `sp-ink`.
- **Scadenza / importante:** fondo pieno `sp-red`, testo e icona bianchi, ombra `sticker-md`. Usarlo con parsimonia, al massimo uno per pagina.
- Tutti: contorno `border-ui` `sp-ink`, raggio 16px, padding 18px 20px, titolo Poppins 700 17px e testo body 16px.
- Mai un bordo colorato solo a sinistra.
