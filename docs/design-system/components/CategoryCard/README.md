# CategoryCard

Scheda di una delle quattro categorie di permesso nella sezione «Trova il tuo permesso».

- Fascia superiore alta 84px in `cat-*` con il nome della categoria (Poppins 800, 22px). Corpo in `cat-*-tint`.
- Contorno `border-ui`, raggio `radius-lg`, ombra `sticker-md`. Un `border-ui` separa la fascia dal corpo.
- Elenco di 3–4 permessi con un chevron a linea; il link «Vedi tutti →» porta al database.
- Mappa delle categorie: Studio/Lavoro `cat-work`, Protezione `cat-protection`, Cure mediche `cat-health`, Motivi familiari `cat-family` (campo Notion `Categoria`).
- Lo stesso schema (fascia + corpo tinta) vale per la scheda del singolo permesso nel database, con i pulsanti Cos'è / Primo rilascio / Rinnovo.
