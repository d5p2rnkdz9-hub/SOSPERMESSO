# NavPill

Voce del menu principale: una pill bianca con contorno e ombra «adesivo».

- Testo stile `button` (Poppins 700, 17px), altezza minima 48px, padding orizzontale 22px.
- Contorno `border-ui` in `sp-ink`, raggio `radius-pill`, ombra `sticker`.
- Le voci con sottomenu hanno un triangolino grigio (`sp-muted`) dopo l'etichetta.
- Badge NUOVO: Poppins 800, 12px, maiuscolo, fondo `badge-new`, bordo 2px `sp-ink`. Al massimo un badge visibile nella barra.
- Il menu NON contiene il pulsante «Fai il test»: i test sono nell'hero.
- Il consumatore fornisce: etichette, href, l'eventuale sottomenu.
