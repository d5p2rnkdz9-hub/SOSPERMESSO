# Icons

Set di 20 icone a linea che sostituiscono le emoji del sito.

- Griglia 24×24, tratto 2px, estremi e giunture arrotondati, `fill="none"`, inchiostro `#141414` (`sp-ink`).
- Nel sito vanno inline (copiando il contenuto dell'SVG) con `stroke="currentColor"`, così prendono il colore del testo. Sul rosso o sul nero usare il bianco.
- Dimensioni: 16px nei badge, 20–26px in pulsanti e avvisi, 32–40px nelle card. Il tratto non va mai sotto 2px a 24px.
- Ogni icona ha il testo accanto; se l'icona è sola (pulsante), serve `aria-label`.
