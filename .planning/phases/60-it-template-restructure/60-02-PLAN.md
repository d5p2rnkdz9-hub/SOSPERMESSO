In `src/pages/permits.liquid`, replace the entire `<!-- PRASSI LOCALI (shared by slug) -->` section (lines 394-437) with a compact accordion version. The section ID `prassi-locali` MUST remain for the tab badge anchor.

Replace with:

```html
<!-- PRASSI LOCALI ACCORDION -->
<section class="section prassi-section bg-off-white" id="prassi-locali">
  <div class="container" style="max-width: 700px;">
    <h2 style="text-align: center; margin-bottom: 0.5rem;">📍 Prassi locali</h2>
    <p style="text-align: center; color: var(--gray-medium); margin-bottom: 1rem; font-size: 0.9rem;">Esperienze condivise dalla community sulle pratiche delle Questure</p>

    {% assign pagePrassi = prassiLocali[permit.slug] %}
    {% if pagePrassi %}
      <div class="prassi-accordion">
        {% for cityGroup in pagePrassi %}
          <div class="prassi-accordion-item">
            <button class="prassi-accordion-header" aria-expanded="false" onclick="this.setAttribute('aria-expanded', this.getAttribute('aria-expanded') === 'true' ? 'false' : 'true'); this.nextElementSibling.classList.toggle('prassi-accordion-open');">
              <span class="prassi-accordion-city">{{ cityGroup[0] }}</span>
              <span class="prassi-accordion-count">{{ cityGroup[1].size }}</span>
              <span class="prassi-accordion-chevron">▸</span>
            </button>
            <div class="prassi-accordion-body">
              {% for practice in cityGroup[1] %}
                <div class="prassi-card" data-prassi-id="{{ practice.id }}">
                  <p class="prassi-card-description">{{ practice.description }}</p>
                  <div class="prassi-card-meta">
                    {% if practice.date %}<span>{{ practice.date }}</span>{% endif %}
                    {% if practice.category %}<span class="prassi-category-tag">{{ practice.category }}</span>{% endif %}
                  </div>
                  <div class="prassi-card-votes">
                    <span class="vote-confermo">Confermo: {{ practice.votiConfermo }}</span>
                    <span class="vote-non-confermo">Non confermo: {{ practice.votiNonConfermo }}</span>
                  </div>
                </div>
              {% endfor %}
            </div>
          </div>
        {% endfor %}
      </div>

      <div style="text-align: center; margin-top: 1rem;">
        <button class="btn btn-primary prassi-submit-btn" onclick="openPrassiModal('https://sospermesso.it/permesso-{{ permit.slug }}.html', '{{ permit.slug }}')">
          Aggiungi la tua esperienza
        </button>
      </div>
    {% else %}
      <div class="prassi-accordion">
        <div class="prassi-accordion-empty">
          <span style="font-size: 1.5rem;">📭</span>
          <p>Nessuna segnalazione finora</p>
          <button class="btn btn-primary prassi-submit-btn btn-sm" onclick="openPrassiModal('https://sospermesso.it/permesso-{{ permit.slug }}.html', '{{ permit.slug }}')">
            Sii il primo a condividere
          </button>
        </div>
      </div>
    {% endif %}
  </div>
</section>
```

Key design decisions:
- The accordion uses `<button>` for headers (accessible, keyboard-focusable)
- Toggle is done via inline onclick that flips `aria-expanded` and toggles a CSS class — NO extra JS file needed, it is 1 line
- City name + count badge shown in collapsed state
- The `.prassi-card` structure inside accordion body is IDENTICAL to the old cards, so `prassi.js` vote enhancement still works (it queries `.prassi-card[data-prassi-id]`)
- The submit button (calling `openPrassiModal`) is preserved
- Empty state shows "Nessuna segnalazione finora" with a CTA to submit first experience
- The `h2` heading now includes the 📍 emoji to match the tab badge
