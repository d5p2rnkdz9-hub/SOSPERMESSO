  font-size: 0.82rem;

  text-decoration: none;
  white-space: nowrap;
  transition: opacity 0.15s, transform 0.15s;
  line-height: 1.4;

  color: #1A1A1A;

    font-size: 0.7rem;
    padding: 0.2rem 0.55rem;
  }
}

**Important considerations:**
- The breadcrumb bar has `position: sticky; top: 130px; z-index: 100`. The tab bar must stack below it with `z-index: 99` and `top` value = breadcrumb top + breadcrumb height. The breadcrumb bar is ~40px tall (0.5rem padding top+bottom + content). So tab bar top = 130 + 40 = 170px desktop, 70 + 40 = 110px mobile.
- Both bars use `position: sticky` so they stack naturally — the tab bar scrolls until it reaches its `top` value, then sticks below the breadcrumb.
- If the front matter `extraStyles` block still has tab-badge styles, remove them from permits.liquid (Task 1 should handle this). The CSS in components.css is the single source of truth for tab-badge styling.

Also add smooth scrolling for the page. Check if `html { scroll-behavior: smooth; }` exists in main.css. If not, add it to the permit tab bar section or to main.css globally. Safest: add `scroll-behavior: smooth;` to `html` in main.css near the top.
