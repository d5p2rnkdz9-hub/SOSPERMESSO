**Change 1: Extract tab badges into sticky bar (outside page header)**

Remove the `permit-tab-badges` div from inside the `<!-- PAGE HEADER -->` section. After the `</section>` that closes the page header, add the sticky tab bar block:

```liquid
  {% unless permit.isPlaceholder == true %}
  <div class="permit-tab-bar" id="permit-tab-bar">
    <div class="container">
      <div class="permit-tab-badges" style="display: flex; flex-wrap: wrap; gap: 0.75rem; justify-content: center;">
        <a href="#cose" class="tab-badge" onclick="return scrollToSection('cose')">Qu'est-ce que c'est</a>
        {% if permit.primoDocuments.size > 0 %}
        <a href="#primo" class="tab-badge tab-badge-primo" onclick="return scrollToSection('primo')">Premier Titre</a>
        {% endif %}
        {% if permit.rinnovoDocuments.size > 0 %}
        <a href="#rinnovo" class="tab-badge tab-badge-rinnovo" onclick="return scrollToSection('rinnovo')">Renouvellement</a>
        {% endif %}
        <a href="#prassi-locali" class="tab-badge tab-badge-prassi" onclick="return scrollToSection('prassi-locali')">Pratiques locales</a>
      </div>
    </div>
  </div>
  <script>
  function scrollToSection(id) {
    var el = document.getElementById(id);
    if (!el) return true;
    var header = document.querySelector('header') || document.querySelector('.site-header');
    var breadcrumb = document.querySelector('.breadcrumb-bar');
    var tabBar = document.getElementById('permit-tab-bar');
    var offset = 20; // extra breathing room
    if (header) offset += header.getBoundingClientRect().height;
    if (breadcrumb) offset += breadcrumb.getBoundingClientRect().height;
    if (tabBar) offset += tabBar.getBoundingClientRect().height;
    var top = el.getBoundingClientRect().top + window.pageYOffset - offset;
    window.scrollTo({ top: top, behavior: 'smooth' });
    return false;
  }
  </script>
  {% endunless %}
```

Note: The `{% unless permit.isPlaceholder == true %}...{% endunless %}` that was wrapping badges inside the header must be REMOVED from the header since it now wraps the external tab bar block. The page header should just have emoji + h1, no badges.
